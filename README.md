# One Page Report — Megasteam

Plataforma integrada de gestão de projetos da Megasteam (One Page Report, ProdControl e Budget Builder).

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Como rodar localmente

```sh
git clone https://github.com/barrach/one-page-report.git
cd one-page-report
npm i
npm run dev
```

Copie `.env.example` (ou peça o `.env` para o time) e preencha as variáveis do Supabase antes de rodar.

## Deploy

O deploy é feito via Vercel, conectado ao branch `main` deste repositório no GitHub.
